# 实现教室内嵌式“研究模式”

## 1. 组件增强 (GoBoard.vue)
- **交互支持**: 添加 `interactive` 模式。
- **事件监听**: 实现 Canvas 点击位置到棋盘坐标的换算逻辑。
- **视觉反馈**: 鼠标悬停在空白处时显示半透明的预览棋子（可选，提升体验）。

## 2. 新增分析组件 (AnalysisModal.vue)
- **UI 结构**: 使用 DaisyUI Modal 承载。
- **状态管理**: 维护一份独立的 `analysisStones` 数组，初始值来自录像当前状态。
- **操作功能**: 
    - 点击落子（黑白交替）。
    - 右键悔棋。
    - 一键恢复（重置为录像初始状态）。

## 3. 逻辑集成 (App.vue & PlayerControls.vue)
- **触发入口**: 在控制栏增加“进入研究”按钮。
- **状态联动**: 点击研究时自动调用 `pause()`，并将当前棋局数据快照传递给分析组件。

## 4. 关键点
- 确保分析模式下的操作不影响后台录像的播放进度。
- 坐标转换需考虑 Canvas 的缩放比例。
