# Ku10 项目重构计划

## 技术选型
1. **框架**: Vue 3 (SFC) + Vite - 保证轻量、响应式且构建速度快。
2. **样式**: Tailwind CSS + DaisyUI - 消除简陋感，提供现代 UI 且不增加多余 JS。
3. **渲染**: HTML5 Canvas - 解决 225 个 DOM 节点的性能瓶颈，支持高帧率动画。
4. **存储**: 预计算状态快照 (Snapshots) - 解决进度条跳转必须重播的问题。

## 实现方案
### 1. 架构重构
- 将 `boardObj` 转换为 Vue 组件 `GoBoard.vue`，使用 Canvas 绘图。
- 将 `recordPlayer` 转换为 `usePlayer` 组合式函数，管理全局播放状态。
- 数据流：JSON -> 预处理器 (生成状态数组) -> 播放引擎 -> Canvas 渲染。

### 2. 进度条优化
- **预处理**: 加载 JSON 后立即计算出每一步的棋盘全量状态。
- **瞬时跳转**: 拖动进度条时，直接通过索引 `states[pointer]` 获取数据并重绘，实现零延迟跳转。

### 3. UI 提升
- 采用 **木质质感** 或 **极简深色** 主题。
- 使用 DaisyUI 的 `Range` 控件重构进度条，`Drawer` 处理移动端列表。
- 增加落子音效支持（预留接口）。

## 关键步骤
1. **环境初始化**: 搭建 Vite + Vue 3 基础环境。
2. **逻辑迁移**: 移植十六进制坐标转换等核心算法。
3. **Canvas 开发**: 实现高性能棋盘绘制逻辑。
4. **UI 集成**: 按照现代 Web 标准重构布局。
5. **数据兼容**: 确保 `trans.json` 和所有旧版 JSON 正常读取。
